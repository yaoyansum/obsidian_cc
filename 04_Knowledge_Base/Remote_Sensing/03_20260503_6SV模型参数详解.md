# 6SV 模型参数详解

6S模型主要包括以下5个部分：

1. **几何关系**：太阳天顶角、太阳方位角、观测天顶角、观测方位角
2. **大气模式**：大气基本成分及温湿度廓线
3. **气溶胶模式**：气溶胶相函数、非对称因子和单次散射反照率等
4. **传感器光谱特性**：通道的光谱响应函数
5. **地表反射率**：均一地表与非均一地表

## 几何参数 (Geometrical Parameters)

参数名称：**iges** | 取值范围：0-7

四个变量：太阳天顶角、太阳方位角、观测天顶角、观测方位角。

- `iges=1-7`: 已有卫星对应的几何参数
- `iges=0`: 用户自定义几何参数

## 大气模式 (Atmospheric Model)

参数名称：**idatm** | 取值范围：0-9

```python
idatm=0: 无气体吸收
idatm=1: 热带大气
idatm=2: 中纬度夏季大气
idatm=3: 中纬度冬季大气
idatm=4: 亚北极区夏季
idatm=5: 亚北极区冬季
idatm=6: 美国标准大气（1962年）
idatm=7: 用户定义大气廓线（34层无线电探空数据）
         包括：高度(km)、气压(mb)、温度(K)、水汽密度(g/m³)、臭氧密度(g/m³)
idatm=8: 输入水汽和臭氧总含量 — 水汽(g/cm²)、臭氧(cm-atm)
idatm=9: 读入无线电探空数据文件
```

![](https://cdn.nlark.com/yuque/0/2024/png/49668464/1730279578490-fcf1a649-8772-4070-888f-b6bd1b9700fd.png)

## 气溶胶类型参数 (Aerosol Model)

参数名称：**iaer** | 取值范围：0-12

```python
iaer=0:  无气溶胶
iaer=1:  大陆型气溶胶
iaer=2:  海洋型气溶胶
iaer=3:  城市气溶胶
iaer=4:  用户自定义四种粒子所占体积百分比：
         灰尘(Dust-like)、水溶型(Water-sol)、海洋型(Ocean)、烟灰(Soot)
iaer=5:  沙漠型气溶胶
iaer=6:  生物质燃烧型
iaer=7:  平流层模式
iaer=8:  多峰对数正态分布（用户自定义尺度分布）
iaer=9:  改进的Gamma分布（用户自定义尺度分布）
iaer=10: Junge幂指数律分布（用户自定义尺度分布）
iaer=11: 按太阳光度计测量结果定义气溶胶模型
         需输入：粒子半径(µm)、粒径分布(dV/d(logr), cm³/cm²/micron)、
         复折射指数实部和虚部谱
iaer=12: 利用事先计算的结果
```

## 气溶胶含量参数 (Concentration)

参数名称：**v** | 能见度必须大于5公里

```python
v = 能见度（公里）
v = 0: 输入550纳米气溶胶光学厚度 taer55
v = -1: 没有气溶胶
```

## 目标高度参数 (Altitude of Target)

参数名称：**xps**

```python
xps >= 0: 目标在海平面高度
xps < 0: 绝对值代表目标高度（公里）
```

![](https://cdn.nlark.com/yuque/0/2024/png/49668464/1730279645109-60e94134-db75-4026-a57c-2f1360cb437c.png)

## 传感器高度参数 (Sensor Altitude)

参数名称：**xpp**

```python
xpp = -1000: 卫星观测
xpp = 0: 地面观测
-100 < xpp < 0: 飞机观测，绝对值代表飞机相对目标高度（公里）
```

> 对于飞机观测，必须输入飞机和地面之间的水汽、臭氧含量和550nm气溶胶光学厚度。如无数据则输入负值，水汽和臭氧根据62年美国标准大气内插，气溶胶则根据2公里指数廓线计算。

## 光谱参数 (Spectral Conditions)

参数名称：**iwave** | 取值范围：-2 ~ 70

虽然在整个波段计算气体透射率和散射函数，但处理强吸收波段吸收与散射的相互作用不精确，因此不适合强吸收带。

```python
iwave = -2 ~ +1: 用户自定义光谱条件
iwave = -2: 输入光谱范围上下限（微米），滤光片函数为1，输出单色结果
iwave = -1: 单色计算，给出单色波长（微米）
iwave = 0: 输入光谱范围上下限（微米），滤光片函数为1
iwave = 1: 输入光谱范围上下限（微米）并输入滤光片函数（间隔0.0025微米）
iwave = 2-70: 选择下列卫星通道
```

> **注：** 利用 MODIS 数据反演 AOT 时，可选择 42（红光波段）和 44（蓝光波段），IDL 调用 6S 分别生成两张查找表，用这两个查找表分别反演 550nm 处的气溶胶光学厚度，然后做平均，提高气溶胶反演精度。

## 地表反射率类型 (Ground Reflectance Type)

可选择"补丁"结构的地表情况，输入半径为 rad 的圆形目标反射率 $roc$ 和周围环境反射率 $roe$。

```python
# 地表类型
inhomo=0: 均匀表面
inhomo=0: 非均匀表面

# BRDF
idirec=0: 无方向效应 — 输入均匀朗伯表面反射率 igroun (roc=roe)
idirec=1: 有方向效应

ibrdf=0: 用户自定义BRDF
ibrdf=1: hapke model
ibrdf=2: verstraete et al. model
ibrdf=3: Roujean et al. model
ibrdf=4: walthall et al. model
ibrdf=5: minnaert model
ibrdf=6: Ocean
ibrdf=7: Iaquinta and Pinty model
ibrdf=8: Rahman et al. model
ibrdf=9: Kuusk's multispectral CR model
```

> **注：** 地表反射率输入有六种形式：0为反射率不随波长变化，1为以2.5nm步长输入反射率，2为绿色植被的平均光谱反射率，3为清水，4为沙地，5为湖水。1为各向异性构建BRDF，其中 `ibrdf=4` (walthall model) 不少论文使用。

## 激活大气校正方式

参数名称：**rapp** | 确保表观反射率为正值

```python
rapp < -1: 不激活大气校正方式
rapp > 0: 反演地面反射率，满足大气层顶的辐射亮度
-1.0 < rapp < 0: 反演地面反射率，满足表观反射率 = -rapp
```
