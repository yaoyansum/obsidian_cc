# QAA 算法在 Landsat 上的应用：Lee 2016 vs Wei 2019

---

## 0. QAA_v6 标准流程（基准算法）

所有公式出处：Lee et al. (2002); IOCCG (2006); QAA_v6 文档。

### Step 0: 输入
Rrs(λ) at multiple bands (sr⁻¹), 水上遥感反射率。

### Step 1: 水上→水下反射率转换
```
rrs(λ) = Rrs(λ) / (0.52 + 1.7 × Rrs(λ))
```
出处：Lee et al. (2002), Eq.(2)。

### Step 2: 计算 u(λ) = bb/(a+bb)
```
u(λ) = (-g0 + √(g0² + 4 × g1 × rrs(λ))) / (2 × g1)
g0 = 0.089, g1 = 0.1245
```
出处：Gordon et al. (1988); Lee et al. (2002), Eq.(3)-(4)。

### Step 3: 确定参考波长 λ0
分支判断：
- 若 Rrs(670) < 0.0015 sr⁻¹ → λ0 = 55x nm（如 555 nm for SeaWiFS）
- 否则 → λ0 = 670 nm

### Step 4: 计算 a(λ0)
**分支 A** (λ0 = 55x nm):
```
χ = log10[(rrs(443) + rrs(490)) / (rrs(55x) + 5 × rrs(670)/rrs(490) × rrs(670))]
a(λ0) = aw(λ0) + 10^(h0 + h1 × χ + h2 × χ²)
h0 = -1.146, h1 = -1.366, h2 = -0.469
```

**分支 B** (λ0 = 670 nm):
```
a(670) = aw(670) + 0.39 × [rrs(670) / (rrs(443) + rrs(490))]^1.14
```

### Step 5: 计算 bbp(λ0)
```
bbp(λ0) = u(λ0) × a(λ0) / (1 - u(λ0)) - bbw(λ0)
```

### Step 6: 计算 η（bbp 光谱斜率）
```
η = 2.0 × (1 - 1.2 × exp(-0.9 × rrs(443) / rrs(55x)))
```

### Step 7: 外推 bbp 到其他波长
```
bbp(λ) = bbp(λ0) × (λ0 / λ)^η
```

### Step 8: 计算各波段 a(λ)
```
a(λ) = (1 - u(λ)) × (bbw(λ) + bbp(λ)) / u(λ)
```

### Step 9: 分解 adg(443)、aph(443)
```
ζ = aph(412)/aph(443) = 0.74 + 0.2 / (0.8 + rrs(443)/rrs(55x))
S = 0.015 + 0.002 / (0.6 + rrs(443)/rrs(55x))
ξ = adg(412)/adg(443) = exp(S × (412 - 443)) = exp(-31 × S)

adg(443) = [a(412) - ζ × a(443)] / [ξ - ζ] - [aw(412) - ζ × aw(443)] / [ξ - ζ]
adg(λ) = adg(443) × exp(S × (443 - λ))
aph(λ) = a(λ) - adg(λ) - aw(λ)
```

## 1. Lee 2016：基于 Landsat-8 的 ZSD 半解析方案

**论文**：Lee, Shang, Qi, Yan, Lin (2016). *A semi-analytical scheme to estimate Secchi-disk depth from Landsat-8 measurements*. Remote Sensing of Environment, 177, 101-112.

**目标**：从 Landsat-8 Rrs 反演 Secchi 盘深度 ZSD（水体透明度）。

### 完整 10 步流程

#### Step 0: 输入
Landsat-8 OLI 大气校正后的 Rrs，4 个可见光波段：
- Band 1 (443 nm), Band 2 (483 nm), Band 3 (561 nm), Band 4 (655 nm)

#### Step 1: 确定 L8 波段代表性波长
**问题**：L8 波段带宽宽 (~60 nm)，不能直接使用中心波长。
**方法**：基于 901 条全球实测高光谱 Rrs，按 RSR 加权计算等效 L8 Rrs，再与高光谱 Rrs 各波长做线性回归，选 bias→0 且 |slope-1|→0 的波长。

**结果**（Lee 2016 Table 1）：
| L8 Band | 中心波长 (nm) | 代表性波长 (nm) |
|---------|-------------|---------------|
| Band 1  | 443         | 443（不变） |
| Band 2  | 483         | 482（slope-1|=0.0028→最小） |
| Band 3  | 561         | **554**（原561处 slope=0.96，bias虽小但有系统偏差；554处|slope-1|=0.0003） |
| Band 4  | 655         | 656（|slope-1|=0.0011） |

> 原因：Band 3 覆盖 525-600 nm，纯水吸收在此区间增长 4 倍，Rrs 在短波侧更高，光谱加权平均使等效波长偏向短波。

#### Step 2: 重新计算 L8 波段纯水 IOPs
**bbw_L8(Bi)** — 直接 RSR 加权平均（Rrs 正比于 bb）：
```
bbw_L8(Bi) = ∫bbw(λ)·RSRi(λ)dλ / ∫RSRi(λ)dλ
```

**aw_L8(Bi)** — 两步法（Rrs 反比于 a）：
```
xw_L8(Bi) = ∫(1/aw(λ))·RSRi(λ)dλ / ∫RSRi(λ)dλ
aw_L8(Bi) = 1 / xw_L8(Bi)
```

高光谱 aw 来源：Lee et al. (2015b) for 400-545 nm; Pope & Fry (1997) for 550-720 nm; Kou et al. (1993) for 725-800 nm。

**结果**（Lee 2016 Table 2）：
| 参数 | Band 1 (443) | Band 2 (482) | Band 3 (554) | Band 4 (656) |
|------|-------------|-------------|-------------|-------------|
| aw (m⁻¹) | 0.005 | 0.011 | 0.064 | 0.368 |
| bbw (m⁻¹) | 0.0021 | 0.0014 | 0.0008 | 0.0004 |

#### Step 3: 应用标准 QAA_v6 反演 a(λ) 和 bb(λ)
**输入**：Rrs_L8(443, 482, 554, 656 nm)，使用 Step 2 的 aw_L8、bbw_L8。

此步即为 QAA_v6 标准流程（第 0 节 Steps 1-9），只是波段替换为 L8 的四个波段。

关键细节：
- 参考波长 λ0：L8 Band 4 (656 nm) 接近 670 nm，使用 QAA 分支 B：
  ```
  a(656) = aw(656) + 0.39 × [rrs(656) / (rrs(443) + rrs(490))]^1.14
  ```
  （Rrs(490) 用 Rrs(482) 近似替代）
- η 估计中 rrs(55x) 使用 rrs(554)
- 由于 L8 无 412 nm 波段，**此步不执行组分分解（Step 9）**

#### Step 4: 计算各波段 Kd(λ)
**公式**（Lee et al., 2013, Eq.(9)）：
```
Kd(λ) = (1 + 0.005 × θs) × a(λ) + (1 - 0.265 × bbw(λ)/bb(λ)) × 4.26 × (1 - 0.52 × e^(-10.8 × a(λ))) × bb(λ)
```
其中 θs 为太阳天顶角（度数），默认 30°。

输出：Kd_L8(443), Kd_L8(482), Kd_L8(554), Kd_L8(656)。

#### Step 5: 光谱间隙填充 — 估算 Kd(530)
**问题**：ZSD 的最透明窗口常位于 500-530 nm，但 L8 无此波段。
**经验关系**（Lee 2016, Eq.(13)），由 338 组实测数据回归得到：
```
Kd(530) = 0.20 × Kd(488) + 0.75 × Kd(555)
```
对 L8 波段：
```
Kd_L8(530) = 0.20 × Kd_L8(482) + 0.75 × Kd_L8(554)
```
验证：R² = 0.99，平均绝对百分比差 ~6.9%。

#### Step 6: 确定最透明波段的 Kd_tr
从 {Kd(443), Kd(482), Kd(530), Kd(554), Kd(656)} 中找到最小值，该值为 Kd_tr。

> 极少数水体最透明窗口在 400-450 nm 范围（超清澈水体），此时 L8 可能信号不足，论文指出这是局限。

#### Step 7: 确定 Rrs_tr（对应透明窗口的 Rrs）
不是通过 Kd(530) 反推，而是直接从 L8 的四个波段 Rrs 中取最大值：
```
Rrs_tr = max{Rrs_L8(443), Rrs_L8(482), Rrs_L8(554), Rrs_L8(656)}
```
因为 Rrs ∝ 1/Kd，Kd 最小的波段即 Rrs 最大的波段。

#### Step 8: 计算 ZSD
**ZSD 模型**（Lee et al., 2015a, Eq.(1)）：
```
ZSD = 1 / (2.5 × Min(Kd_tr, 0.2)) × ln(|0.14 - Rrs_tr| / 0.013)
```
其中 Min(Kd_tr, 0.2) 防止极端清澈水体 Kd 过小时 ZSD 被高估。

#### Step 9: 验证精度
通过与 197 个实测站点对比（ZSD 范围 0.1-30 m）：
- R² = 0.96
- 平均绝对百分比差 = 16.7%（与使用窄带多光谱 Rrs 的结果几乎相同）
- 无需针对不同水体调整算法参数

#### Step 10（应用示例）：L8 影像处理
- 影像：LC81190432013216LGN00，2013-08-04，厦门九龙江河口
- 大气校正：Acolite 算法（Vanhellemont & Ruddick, 2015b）
- 输出 ZSD 图：外海 ~2 m → 河口 <0.3 m，空间梯度与实地观测一致

## 2. Wei 2019 - SAVE：Landsat-8 组分吸收系数反演

**论文**：Wei, Lee, Shang, Yu (2019). *Semianalytical Derivation of Phytoplankton, CDOM, and Detritus Absorption Coefficients From the Landsat 8/OLI Reflectance in Coastal Waters*. JGR: Oceans, 124, 3682-3699.

**目标**：从 Landsat-8/OLI 反演浮游植物吸收 aph、CDOM 吸收 ag、碎屑吸收 ad。

### 核心问题
L8 OLI 只有 4 个可见光波段 λ1-4 (443, 482, 561, 655 nm)，缺少 **412 nm 波段**。QAA Step 9 中分解 aph 和 adg 需要：
```
adg(443) = [a(412) - ζ×a(443)] / [ξ-ζ] - [aw(412) - ζ×aw(443)] / [ξ-ζ]
```
没有 Rrs(412) → 没有 rrs(412) → 没有 u(412) → 没有 a(412) → 无法分解 adg(443) 和 aph(443)。

### 完整 12 步流程

#### Step 0: 输入
Rrs_L8(443, 482, 561, 655 nm) ← 缺失 412 nm

#### Step 1: 构建 LUT（Look-Up Table）
**数据来源**：
- NOMAD 实测数据（454 条，全球水体）
- Hydrolight 模拟数据（基于 NOMAD IOPs 正演 Rrs）

**处理**：
- 对所有高光谱 Rrs 按 OLI 光谱响应函数 RSRi 卷积到 λ1-4（Eq.1）：
  ```
  Rrs(λi) = ∫Rrs(λ)·RSRi(λ)dλ / ∫RSRi(λ)dλ,  i=1,2,3,4
  ```
- 从高光谱数据插值得到 Rrs(412)（5 nm 窄带，不卷积）
- 得到 LUT 中每条记录为 5 波段 Rrs(412, 443, 482, 561, 655)

#### Step 2: RSS 归一化（Eq.2）
对 LUT 中每条光谱做归一化，保留光谱形状和曲率：
```
nRrs*(λi) = Rrs(λi) / √(ΣRrs(λj)²),  j = 0,1,2,3,4 (j=0 对应 412 nm)
```
性质：
- 波段比值不变：nRrs*(λi)/nRrs*(λk) = Rrs(λi)/Rrs(λk)
- 光谱曲率不变
- 取值范围 [0, 1]
- RSS = 1：√(Σ nRrs*(λj)²) = 1

#### Step 3: 余弦距离匹配
对输入 Rrs(λ1-4)，计算与 LUT 中每条归一化光谱的余弦距离（Eq.3）：
```
d = 1 - Σ[nRrs*(λi) × Rrs(λi)] / [√ΣnRrs*(λi)² × √ΣRrs(λi)²]
```
其中 i=1,2,3,4（仅使用 4 个已知波段）。

选择 d 最小的 LUT 记录作为最佳匹配。

#### Step 4: 估计 Rrs(412)
假设最佳匹配的 nRrs* 光谱形状与输入一致，且 Rrs 新光谱的 RSS 归一化后等于匹配到的 nRrs*(412)（Eq.4）：
```
Rrs(412) / √(Rrs(412)² + ΣRrs(λi)²) ≈ nRrs*(412)
```
求解（Eq.5-6）：
```
A = √(ΣRrs(λi)²) / √(ΣnRrs*(λi)²)   ← 缩放因子
Rrs(412) = A × nRrs*(412)
```
至此获得完整 5 波段 Rrs(412, 443, 482, 561, 655)。

**精度**：MAPD 7% (NOMAD) / 11% (SeaBASS)。

#### Step 5: Rrs(655) → Rrs(670) 转换
**原因**：QAA Step 3 中 λ0 选择在 670 nm 附近，L8 Band 4 为 655 nm，需转换（Eq.7, R²=0.99）：
```
Rrs(670) = 10^(P1X³ + P2X² + P3X + P4)
X = log10(Rrs(655))
P1 = 0.0775, P2 = 0.6585, P3 = 2.7692, P4 = 1.433
```

#### Step 6: 完整 QAA_v6 反演
输入 5 波段 Rrs(412, 443, 482, 561, 670)，执行 QAA_v6 标准流程（第 0 节 Steps 1-9）：

**Step 6.1**: Rrs → rrs (Step 1)
```
rrs(λ) = Rrs(λ) / (0.52 + 1.7Rrs(λ)) for λ = 412, 443, 482, 561, 670
```

**Step 6.2**: u(λ) = bb/(a+bb) (Step 2)
```
u(λ) = (-0.089 + √(0.089² + 4×0.1245×rrs(λ))) / (2×0.1245)
```

**Step 6.3**: 参考波长（Step 3）
由于 Rrs(670) < 0.0015 或 ≥ 0.0015 分两支。Wei 使用 Rrs(670) 直接作为 λ0。

**Step 6.4**: a(670)（Step 4 - 分支 B）
```
a(670) = aw(670) + 0.39 × [rrs(670) / (rrs(443) + rrs(490))]^1.14
```

**Step 6.5**: bbp(670)（Step 5）
```
bbp(670) = u(670)×a(670)/(1-u(670)) - bbw(670)
```

**Step 6.6**: η（Step 6）
```
η = 2.0 × (1 - 1.2 × exp(-0.9 × rrs(443)/rrs(561)))
```

**Step 6.7**: bbp(λ)（Step 7）
```
bbp(λ) = bbp(670) × (670/λ)^η
```

**Step 6.8**: a(λ) at all bands（Step 8）
```
a(λ) = (1-u(λ)) × (bbw(λ)+bbp(λ)) / u(λ)
```
特别得到 a(412) 和 a(443)。

**Step 6.9**: 组分分解（Step 9）
```
ζ = 0.74 + 0.2 / (0.8 + rrs(443)/rrs(561))
S = 0.015 + 0.002 / (0.6 + rrs(443)/rrs(561))
ξ = exp(S × (412 - 443)) = exp(-31 × S)

adg(443) = [a(412) - ζ×a(443)] / [ξ-ζ] - [aw(412) - ζ×aw(443)] / [ξ-ζ]
adg(λ) = adg(443) × exp(S × (443 - λ))
aph(443) = a(443) - adg(443) - aw(443)
```

输出：aph(443) 和 adg(443)。

#### Step 7: 进一步分解 adg → ag + ad

**背景**：标准 QAA 不分解 adg（CDOM+碎屑），因为两者光谱行为相似。Wei 采用 Dong et al. (2013) 经验算法。

**Step 7.1**: 计算非水总吸收（Eq.14 间接）：
```
apg(443) = a(443) - aw(443)   ← 非水总吸收 = adg + aph
```

**Step 7.2**: 计算中间参数 σ（Eq.16）：
```
σ = 0.05 × apg(443) + bbp(561)^1.4 × Rrs(561) / (Rrs(443) × (Rrs(561) + Rrs(670)))
```

**Step 7.3**: 计算 detritus 吸收 ad(443)（Eq.15）：
```
ad(443) = 0.6 × σ^0.9
```

**Step 7.4**: 外推 ad(λ) 光谱（Eq.17）：
```
ad(λ) = ad(443) × exp(-Sd × (λ - 443)),  Sd = 0.012 nm⁻¹ (Babin et al., 2003)
```

**Step 7.5**: 通过差值得到 CDOM 吸收 ag(λ)：
```
ag(λ) = adg(λ) - ad(λ)
```

#### Step 8: 最终输出
- aph(443): 浮游植物吸收系数
- ag(443): CDOM 吸收系数（与 DOC 强相关）
- ad(443): 碎屑（非藻类颗粒）吸收系数

#### Step 9: 验证精度

| 参数 | NOMAD MAPD | SeaBASS MAPD |
|------|-----------|-------------|
| Rrs(412) 估计 | 7% | 11% |
| a(412) | 19% | 17% |
| a(443) | 18% | 19% |
| aph(443) | 30% | 39% |
| adg(443) | 30% | 32% |
| ag(443) | 35% | 46% |
| ad(443) | **67%** | **56%** |

#### Step 10-12: 更多分析

**Step 10 - 敏感性分析**：Rrs(412) 误差 ±20% 时，aph/ag 误差可达 ±45%，ad 不受影响（不依赖 Rrs(412)）。

**Step 11 - 影像应用**：L8 影像 LC80120312015240 (2015-08-28, Boston Harbor)，输出 aph/adg/ag 产品。

**Step 12 - 推广**：SAVE 框架可替换 QAA 为其他 SA 算法（如 GIOP），支持 Sentinel-2 MSI、Landsat 9 OLI-2。

## 3. 数值示例：两种方法对比

### 3.1 设定相同的 L8 输入 Rrs

假设某近岸水体，大气校正后 Rrs 值（单位：sr⁻¹）：
| 波段 | Rrs |
|------|-----|
| 443 nm | 0.0085 |
| 482 nm | 0.0092 |
| 561 nm | 0.0068 |
| 655 nm | 0.0012 |

### 3.2 Wei 2019 的走向

**目标**：算出 aph(443) 和 ag(443)。

**Step 1-4 (虚拟波段)**：
- 从 LUT 匹配到最接近的光谱 → nRrs*(412) = 0.52
- A = √(0.0085²+0.0092²+0.0068²+0.0012²) / √(nRrs*² 各波段和)
- 假设 A ≈ 0.018 → Rrs(412) = 0.018 × 0.52 = 0.0094 sr⁻¹

**Step 5 (655→670)**：
- X = log10(0.0012) = -2.92
- Rrs(670) ≈ 10^(0.0775×(-2.92)³ + 0.6585×(-2.92)² + 2.7692×(-2.92) + 1.433)
- ≈ 10^(-1.94 + 5.61 - 8.08 + 1.43) = 10^(-2.98) ≈ 0.00105 sr⁻¹

**Step 6-8 (QAA + 分解)**：
- rrs(412) = 0.0094/(0.52+1.7×0.0094) ≈ 0.0175
- rrs(443) = 0.0085/(0.52+1.7×0.0085) ≈ 0.0159
- ...
- η = 2.0×(1-1.2×exp(-0.9×0.0159/0.0128)) ≈ 1.2
- ...
- 最终得到:
  - aph(443) ≈ 0.08 m⁻¹
  - adg(443) ≈ 0.45 m⁻¹
  - 进一步分解 → ag(443) ≈ 0.38 m⁻¹, ad(443) ≈ 0.07 m⁻¹

**结论**：该水体 CDOM 主导吸收，浮游植物贡献较小。

### 3.3 Lee 2016 的走向

**目标**：算出 ZSD（透明度）。

**Step 1-3 (QAA)**：与 Wei 相同的 QAA 核心，但无需 412 nm 和 670 nm 转换，直接使用 4 个 L8 波段。

**Step 4 (Kd 计算, θs=30°)**：
- Kd(443) ≈ 0.32 m⁻¹
- Kd(482) ≈ 0.28 m⁻¹
- Kd(554) ≈ 0.38 m⁻¹
- Kd(656) ≈ 1.85 m⁻¹

**Step 5 (间隙填充 530 nm)**：
- Kd(530) = 0.20 × 0.28 + 0.75 × 0.38 = 0.34 m⁻¹

**Step 6 (最透明窗口)**：
- Kd_tr = min(0.32, 0.28, 0.34, 0.38, 1.85) = 0.28 m⁻¹ (482 nm)

**Step 7 (对应 Rrs_tr)**：
- Rrs_tr = max(0.0085, 0.0092, 0.0068, 0.0012) = 0.0092 sr⁻¹ (482 nm)

**Step 8 (ZSD)**：
- ZSD = 1/(2.5×0.28) × ln(|0.14-0.0092|/0.013)
- = 1/0.70 × ln(0.1308/0.013)
- = 1.43 × ln(10.06)
- = 1.43 × 2.31 ≈ 3.3 m

**结论**：该水体透明度约 3.3 米。

### 3.4 两种方法结论对比

| 项目 | Lee 2016 | Wei 2019 |
|------|----------|----------|
| 输入波段数 | 4 (无 412) | 4+虚拟 412 + 转换 670 |
| 关键中间产物 | Kd(530) 经验估算 | Rrs(412) LUT 匹配 |
| 最终输出 | ZSD = 3.3 m | aph(443)=0.08, ag(443)=0.38 (m⁻¹) |
| 物理含义 | "水有多清" | "水里有什么" |

## 4. 关键区别总结

| 对比维度 | Lee 2016 | Wei 2019 |
|----------|----------|----------|
| 待解决的 L8 缺失波段 | ~530 nm（ZSD 最透明窗口） | 412 nm（QAA 分解必需） |
| 填补策略 | 经验回归：Kd(530)=0.20Kd(482)+0.75Kd(554) | LUT 余弦匹配 + 缩放因子估算 Rrs(412) |
| 额外转换步骤 | 无（直接用 655 nm） | 多项式 Rrs(655)→Rrs(670) |
| 是否需要 412 nm | 否（不分解组分） | 是（QAA 分解必需） |
| 最终产物 | ZSD (m)、Kd(λ) | aph(443)、ag(443)、ad(443) (m⁻¹) |
| 是否分解 adg | 否 | 是（Dong et al. 经验算法） |
| 误差链 | QAA 误差 + 530nm 回归误差 | QAA 误差 + Rrs(412)估计误差 + 655→670 转换误差 + ad 分解误差 |
| 验证范围 | ZSD 0.1-30 m | a(443) 0.01-3 m⁻¹ |
| 核心优势 | 简单、ZSD 是管理常用指标、统一机制 | 组分分离、ag 与 DOC 相关、aph 优于 Chl a |
| 主导局限 | 不输出组分吸收、超清水体信号不足 | ad 精度低 (MAPD~60%)、步骤多误差累积 |

## 一句话区分

- **Lee 2016**：补 530 nm → 算 ZSD（水有多清）
- **Wei 2019**：补 412 nm → 走完整 QAA 分解 aph/ag/ad（水里有什么）
