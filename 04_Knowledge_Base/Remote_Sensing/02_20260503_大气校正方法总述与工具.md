## Acolite

**Reference:** *acolite_manual_20231023*

### 方法原理

#### DSF (Dark Spectrum Fitting) — 气溶胶校正

1. DSF 根据场景或子场景中的多个暗目标计算气溶胶光学厚度 ($\tau_{a}$ 550 nm)。
2. 对于每个波段，最暗的对象根据 (1) 绝对最小值、(2) 一个百分位数、(3) 从OLS拟合到直方图中前一千个像素的偏移量来估计，创建"暗光谱"，即 $\rho_{dark}$。
3. Four settings for the DSF: `fixed`、`tiled`、`segmented`、`resolved`。

#### Glint Correction — 太阳耀斑校正

默认情况下使用SWIR波段来估计耀斑信号。

#### EXP (Exponential Extrapolation)

使用两个波段的瑞利校正反射率来估计气溶胶反射率 ($\rho_{am}$)。

### Inputs

输入文件可以是**单个文件**（如 CHRIS .hdf 文件或压缩的 Planet bundles）或**目录**（如 Sentinel .SAFE bundles 或解压的 Planet bundles）。

![](https://cdn.nlark.com/yuque/0/2024/png/49668464/1729496380847-113cc321-036c-43ac-92f9-5f3513a6a019.png)

### Outputs

两个 NetCDF 文件：

1. **Level 1** — 大气层顶反射率 ($\rho_t$, rhot_*), L1R
2. **Level 2** — 地表反射率 ($\rho_s$, rhos_*), L2R

如果原始输入数据位于 GeoTIFF 支持的投影中，可以将 NetCDF 数据集输出为 **GeoTIFF 文件**。

### Ancillary Data

1. 需要设置 EarthData 帐户 ([https://earthdata.nasa.gov](https://earthdata.nasa.gov))，账户需要获得 OB 的批准。
2. 发现使用辅助数据与不使用辅助数据之间的**差异非常小** (Vanhellemont, 2020c)。
3. 用户名和密码可通过 `.netrc` 文件或在 `config.txt` 中提供。

### LUTs (Look-up Tables)

1. 从 [https://github.com/acolite/acolite_luts](https://github.com/acolite/acolite_luts) 手动获取 LUT。
2. LUT 应放在 `acolite/data/LUT` 目录中，保持文件结构 `acolite_luts`。

例如处理 L8_OLI 数据：

```
https://github.com/acolite/acolite_luts/tree/main/ACOLITE-LUT-202110/L8_OLI
https://github.com/acolite/acolite_luts/tree/main/ACOLITE-LUT-202110-Reverse/L8_OLI
https://github.com/acolite/acolite_luts/tree/main/Gas
https://github.com/acolite/acolite_luts/tree/main/RSKY-202102/L8_OLI
https://github.com/acolite/acolite_luts/tree/main/WV
```

转换为：

```
acolite/data/LUT/ACOLITE-LUT-202110/L8_OLI
acolite/data/LUT/ACOLITE-LUT-202110-Reverse/L8_OLI
acolite/data/LUT/Gas
acolite/data/LUT/RSKY-202102/L8_OLI
acolite/data/LUT/WV
```

### 安装

安装网址：[https://github.com/acolite/acolite](https://github.com/acolite/acolite) 版本 20231023

```bash
# 1. 创建环境
conda create -n acolite -c conda-forge python=3

# 2. 安装依赖
conda install -c conda-forge numpy matplotlib scipy gdal pyproj scikit-image pyhdf pyresample netcdf4 h5py requests pygrib cartopy

# 3. 安装JP2支持（处理MSI、WFV等）
conda install -c conda-forge libgdal-jp2openjpeg

# 4. 激活环境
conda activate acolite

# 5. 启动GUI
python launch_acolite.py

# 6. 配置EarthData
# 新建txt文件，输入：machine earthdata login test_account password test_pwd
# 修改为 .netrc 保存；或在 config.txt 中提供
```

> **注释：** GDAL在处理PG2等文件（MSI、WFV等）时存在打开失败的问题，使用 `libgdal-jp2openjpeg` 替换GDAL读取影像的库。

**单处理：**

```bash
python launch_acolite.py --cli --settings=settings_file
```

**批处理：**

```bash
python launch_acolite.py --cli --settings=settings_file --inputfile="file1,file2,file3"
```

**获取 LUTs：**

```bash
# 所有支持的多光谱传感器

# 高光谱传感器通用LUT
python launch_acolite.py --retrieve_luts --sensor hyper
```

## POLYMER

### 环境安装

#### 1. 创建环境并安装依赖

```bash
conda create -n polymer -c conda-forge mamba
conda activate polymer
mamba env update -f environment.yml
```

> Tips：如果编译不通过，可以降低编译版本，如 `cython==0.29.**`

![](https://cdn.nlark.com/yuque/0/2024/png/49668464/1730336334902-9128c10b-4935-4599-b5c1-15dafa29313b.png)

#### 2. 下载辅助数据

```bash
make auxdata_all
```

#### 3. 编译

```bash
make
```

编译完成的 `.so` 文件放在 `envs/envs_name/lib/python3.13/site-packages/`

**setup.py 示例：**

```python
from distutils.core import setup
from distutils.extension import Extension
from pathlib import Path
import numpy
from Cython.Build import cythonize

def main():
    NAME = "Polymer"
    DESC = "Polymer atmospheric correction algorithm (http://dx.doi.org/10.1364/OE.19.009783)"
    SRC_DIR = 'polymer'
    DEBUG = False
    ANNOTATE = True

    if DEBUG:
        compiler_directives = {
            'profile': True,
            'embedsignature': True,
            'language_level': '3',
        }
    else:
        compiler_directives = {
            'boundscheck': False,
            'initializedcheck': False,
            'cdivision': True,
            'embedsignature': True,
            'language_level': '3',
        }

    setup(
        name=NAME,
        description=DESC,
        ext_modules=cythonize(
            [Extension('*', sources=['polymer/*.pyx'],
                       define_macros=[('NPY_NO_DEPRECATED_API', 'NPY_1_7_API_VERSION')])],
            build_dir='build',
            compiler_directives=compiler_directives,
            annotate=ANNOTATE,
            nthreads=4,  # Windows 换成 1
        ),
        include_dirs=[numpy.get_include()],
    )

if __name__ == '__main__':
    main()
```

### Ancillary Data

#### 1. NASA Ancillary Data

设置 NASA 登录密码：

```bash
cd ~
touch .netrc
echo "machine urs.earthdata.nasa.gov login uid_goes_here password password_goes_here" > .netrc
chmod 0600 .netrc
```

使用方式：

```python
from polymer.ancillary import Ancillary_NASA
Level1(<filename>, ancillary=Ancillary_NASA())
```

> **NOTE:** `Ancillary_NASA` 有默认选项自动下载和选择最近的数据集，存储在 `ANCILLARY/METEO/` 文件夹。该文件夹通过 `make ancillary` 或 `make all` 初始化。

**参数说明：**
- `meteo`: NCEP 文件名（无插值）或元组 (meteo1, meteo2)（有插值），若为None搜索最近的2个并激活插值
- `ozone`: ozone 文件名，若为None搜索最近的文件
- `directory`: 辅助数据本地存储目录
- `offline` (bool): 离线模式，不尝试下载
- `allow_forecast` (bool, default True): 允许使用NCEP预报数据
- `allow_standard` (bool, default True): 允许使用其他非预报数据

**示例：**

```python
meteo=None, ozone=None,
directory='ANCILLARY/METEO/',
offline=False,
allow_standard=True,
allow_forecast=True,
delta=None,
met_patterns=None, ozone_patterns=None
```

#### 2. ERA-Interim Ancillary Data

地址：[https://www.ecmwf.int/en/forecasts/datasets/reanalysis-datasets/era-interim](https://www.ecmwf.int/en/forecasts/datasets/reanalysis-datasets/era-interim)

需要以下 Python 模块：
- `ecmwf` python api client（需 ECMWF key）
- `pygrib`（读取 GRIB 格式）

```python
from polymer.ancillary_era import Ancillary_ERA
Level1(<filename>, ancillary=Ancillary_ERA())
```

**参数：**
- `directory`: ERA-Interim 文件存储目录
- `pattern`: GRIB 文件存储模式 (%Y, %m, %d)
- `offline`: 离线模式

**示例：**

```python
directory='ANCILLARY/ERA-Interim/',
pattern='%Y/era_interim_%Y%m%d.grib',
offline=False
```

#### 3. ERA5 Ancillary Data

地址：[https://www.ecmwf.int/en/forecasts/datasets/reanalysis-datasets/era5](https://www.ecmwf.int/en/forecasts/datasets/reanalysis-datasets/era5)

需要以下 Python 模块：
- `cdsapi`（需 CDS API key）
- `xarray`

```python
from polymer.ancillary_era5 import Ancillary_ERA5
Level1(<filename>, ancillary=Ancillary_ERA5())
```

**参数：**
- `directory`: ERA5 文件存储目录
- `pattern`: NetCDF 文件存储模式
- `offline` (bool, default False)

**示例：**

```python
directory='ANCILLARY/ERA5/',
pattern='%Y/%m/%d/era5_%Y%m%d_%H%M%S.nc',
time_resolution=1,
offline=False,
```

### Input Data

支持 FF (reduced resolution) 和 FR (full resolution) 格式。

**MERIS/Envisat：**

```python
Level1_MERIS('MER_RR__1PRACR20050501_092849_000026372036_00480_16566_0000.N1')
```

**OLCI/Sentinel-3：**

```python
Level1_OLCI('S3A_OL_1_EFR____20170123T102747_20170123T103047_20170124T155459_0179_013_279_2160_LN1_O_NT_002.SEN3')
```

**MODIS/Aqua, SeaWiFS, VIIRS：**

```python
from polymer.level1_nasa import *
Level1_MODIS('A2010120124000.L1C')
Level1_SeaWiFS('S2000116121145.L1C')
Level1_VIIRS('V2013339115400.L1C')
```

**MSI/Sentinel-2：**

```python
Level1_MSI('S2A_OPER_PRD_MSIL1C_PDMC_20160504T225644_R094_V20160504T105917_20160504T105917.SAFE/GRANULE/S2A_OPER_MSI_L1C_TL_SGS__20160504T163055_A004524_T30TXR_N02.02')
```

**ASCII Input：**

通过 `Level1_ASCII` 类。

**SNAP 子集产品：**

`Level1_NETCDF` 可读取 SNAP 导出的 netCDF4 格式的 MERIS、OLCI 或 Sentinel-2 产品。

### Output

输出文件格式可为 hdf4 或 netcdf。
