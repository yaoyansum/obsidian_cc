# 内陆水体"活性管道"模型——Cole（2007）与Tranvik（2009）综述

> 基于两篇开创性综述的系统梳理
> 总结日期：2026-05-07
>
> - Cole, J.J. et al. (2007). Plumbing the Global Carbon Cycle: Integrating Inland Waters into the Terrestrial Carbon Budget. *Ecosystems*, 10, 171–184.
> - Tranvik, L.J. et al. (2009). Lakes and reservoirs as regulators of carbon cycling and climate. *Limnology and Oceanography*, 54(6, part 2), 2298–2314.

---

## 一、背景与核心问题

传统全球碳循环模型通常将生物圈简化为三个"箱体"——陆地、海洋和大气，通过气体交换相连（Bolin 1981；IPCC 2001）。在这一框架中，内陆水体（湖泊、河流、水库）被忽略或仅被视为将碳从陆地被动输送到海洋的"中性管道"（neutral pipe）。

这两篇文章的核心贡献在于**推翻了"中性管道"假说**，建立了内陆水体作为碳循环"活性管道"（active pipe）的新范式：

- **Cole et al.（2007）**首次系统量化了内陆水体在碳循环中的各项通量，证明内陆水体是陆地碳的活跃转化器
- **Tranvik et al.（2009）**在此基础上更新了全球估算，进一步探讨了湖泊对未来气候变化的响应与反馈

## 二、Cole et al.（2007）：内陆水体碳收支

### 2.1 质量平衡框架

文章提出简化的质量平衡方程：

**I = G + S + E**

其中：
- **I（Import）**：陆地输入内陆水体的碳
- **G（Gas exchange）**：水体与大气之间的净气体交换
- **S（Storage）**：沉积物中的碳埋藏
- **E（Export）**：通过河流和地下水向海洋的输出

### 2.2 核心定量结果

| 通量组分 | 估算值（Pg C yr⁻¹） | 说明 |
|---------|-------------------|------|
| 陆地输入内陆水体（I） | **1.9** | 保守估计，纳入洪泛区可达2.8 |
| CO₂释放到大气（G） | **0.75** | 湖泊0.11 + 水库0.28 + 河流河口0.35 + 地下水0.01 |
| 沉积物埋藏（S） | **0.23** | 湖泊0.05 + 水库0.18 |
| 输出到海洋（E） | **0.9** | 有机碳0.45 + 无机碳0.26 + 地下水0.19 |
| 甲烷排放 | **0.008–0.048** | 占CO₂-C排放的约4%（GWP约20倍） |

### 2.3 关键发现

1. **陆地输入远超海洋输出**：陆地输入（1.9 Pg C yr⁻¹）是海洋输出（0.9 Pg C yr⁻¹）的2倍以上，表明内陆水体不是被动管道

2. **内陆水体是净CO₂源**：约**40%** 的陆地输入碳以CO₂形式返回大气

3. **沉积碳储量巨大**：全新世湖泊沉积物含约**820 Pg C**，相当于陆地生物量（~460 Pg）的1.8倍或土壤碳（~1,395 Pg）的约30–60%

4. **单位面积碳通量高**：湖泊碳埋藏速率（4.5–14 g C m⁻² yr⁻¹）远高于森林土壤（~1.2 g C m⁻² yr⁻¹）

### 2.4 各组分分解

**CO₂释放：**
- **湖泊**：0.11（0.07–0.15）Pg C yr⁻¹，基于约5,000个湖泊的全球数据集
- **水库**：0.28 Pg C yr⁻¹，约天然湖泊的2倍
- **河流与河口**：0.35 Pg C yr⁻¹（保守估计），仅考虑主河道
- **洪泛区**：若纳入，可增加0.9 Pg C yr⁻¹（单亚马逊区域估算）
- **地下水**：0.01（0.003–0.03）Pg C yr⁻¹

**碳埋藏：**
- **天然湖泊**：0.05（0.03–0.07）Pg C yr⁻¹
- **水库**：0.18（0.16–0.2）Pg C yr⁻¹，单位面积埋藏速率极高（~400 g C m⁻² yr⁻¹）
- 小型湖泊和农业池塘可能在总量中占更重要地位

**碳输出：**
- 河流有机碳：0.45（0.38–0.53）Pg C yr⁻¹
- 河流无机碳（主要为HCO₃⁻）：0.26（0.21–0.3）Pg C yr⁻¹
- 海底地下水排放（SGD）：0.13–0.25 Pg C yr⁻¹

### 2.5 区域案例

| 区域 | 关键发现 |
|------|---------|
| 亚马逊 | 纳入洪泛区的CO₂净通量后，热带雨林从碳汇转为可能不固碳（Richey et al., 2002） |
| 北极冻原 | 约**20%** 的陆地NEP通过湖泊和河流的气体通量返回大气（Kling et al., 1991） |
| 芬兰 | 覆盖10%面积的湖泊每年排放约**20%** 的森林+土壤年碳积累量 |
| 波罗的波的尼亚湾 | 约一半的流域有机碳输出在湖泊和河流中被呼吸并释放到大气 |

## 三、Tranvik et al.（2009）：更新估算与未来展望

### 3.1 更新的全球湖泊分布

- 全球湖泊数量：**3.04亿个**（Downing et al., 2006）
- 全球湖泊总面积：**420万 km²**
- 平均湖泊面积仅 **0.012 km²**，小型湖泊（0.001–0.01 km²）占绝大部分（2.77亿个）
- 湖泊和水库覆盖大陆面积 > **3%**（高于此前的认识）

### 3.2 修订的碳通量估算

在Cole et al.（2007）基础上，Tranvik et al.（2009）给出了显著更高的估算：

| 通量 | Cole et al.（2007） | Tranvik et al.（2009）修订 |
|-----|-------------------|--------------------------|
| 湖泊CO₂排放 | 0.11 Pg C yr⁻¹ | **0.53 Pg C yr⁻¹**（纳入热带湖泊、盐湖） |
| 河流网络CO₂排放 | 0.35 Pg C yr⁻¹ | +0.32 Pg C yr⁻¹（纳入溪流，Battin et al., 2008） |
| **内陆水体总CO₂排放** | **0.75 Pg C yr⁻¹** | **~1.4 Pg C yr⁻¹** |
| **沉积物碳埋藏** | **0.23 Pg C yr⁻¹** | **~0.6 Pg C yr⁻¹**（纳入小水库和池塘） |
| **陆地总输入（I）** | **1.9 Pg C yr⁻¹** | **~2.9 Pg C yr⁻¹** |

### 3.3 与全球碳收支的对比

修订后的内陆水体碳通量与主要全球碳通量相当：

| 通量 | 数值 | 对比 |
|-----|------|------|
| 内陆水体CO₂排放 | **1.4 Pg C yr⁻¹** | ≈ 海洋CO₂吸收（2.6 Pg C yr⁻¹）的~54% |
| 内陆水体碳埋藏 | **0.6 Pg C yr⁻¹** | > 海洋沉积物有机碳埋藏（0.12 Pg C yr⁻¹）的4–5倍 |
| 化石燃料燃烧 | 6.4 Pg C yr⁻¹ | 内陆水体排放≈化石燃料的~22% |
| 森林砍伐碳排放 | 1.6 Pg C yr⁻¹ | 内陆水体排放≈森林砍伐的~88% |
| 陆地NEP | ~2 Pg C yr⁻¹ | 内陆水体处理量≈陆地NEP的100%+ |

### 3.4 碳在湖泊中的三种归宿

论文提出湖泊中碳的三大主要路径（图2、表1）：

1. **沉积作用**：DOC/POC通过絮凝、生物裹挟、沉降进入沉积物
2. **矿化作用**：DOC/POC通过微生物降解和光化学降解转化为温室气体（CO₂、CH₄）
3. **下游输送**：碳化合物通过河流、地下水系统向下游输送

这三种路径的相对重要性决定了湖泊是温室气体源还是汇。

### 3.5 湖泊碳循环的关键过程

**1. 外源碳输入**
- DIC和DOC是大多数湖泊的主要碳输入形式
- DOC在湿润热带和非碳酸盐北方森林区占主导
- DIC在温带、碳酸盐岩区和北方森林中占主导
- 碳输入的纬度差异反映气候、土壤质地和土地利用的影响

**2. 内源初级生产**
- 全球湖泊GPP约**0.65 Pg C yr⁻¹**（可能被低估，因未充分计入小型湖泊）
- 大多数小型湖泊浅而光照充足，可能是地球上最高产的生态系统之一

**3. 微生物矿化**
- 大多数湖泊中呼吸作用超过初级生产，导致CO₂过饱和
- 沉积物呼吸的相对重要性受水深强烈影响
- 小型浅水湖泊中沉积物与上层混合水接触，有利于矿化而非埋藏

**4. 甲烷排放**
- 天然湖泊：8–48 Tg CH₄ yr⁻¹（Bastviken et al., 2004）
- 大型水库：~70 Tg CH₄ yr⁻¹（St. Louis et al., 2000）
- 考虑CH₄的20倍GWP后，湖泊CO₂和CH₄的气候强迫大致相当
- 浅水湖泊中CH₄主要通过气泡（ebullition）释放

**5. 沉积物碳埋藏**
- 长期间平均碳埋藏速率：**4.5–14 g C m⁻² yr⁻¹**
- 小型富营养化湖泊和水库埋藏速率最高（平均可达1,000 g C m⁻² yr⁻¹以上）
- DOC可通过絮凝转化为POC并沉降埋藏（在北方湖泊中该通量可与CO₂排放相当）

### 3.6 气候变化情景下的未来预测

**水文变化：**
- 降水格局变化将影响碳输入数量和停留时间
- 干旱导致停留时间延长→更多光化学降解→有色DOC减少
- 湿润气候增加DOC输出→停留时间短→更多DOC存留

**植被与土壤：**
- 温度升高改变植物物种组成
- 升高的CO₂增加植物碳固定→增加DOC产量但降低生物可利用性
- 高纬度土壤有机质分解加速→更多陆源DOC输入湖泊

**分层与缺氧：**
- 变暖导致更长时间和更强分层→底层缺氧加剧
- 缺氧环境下：
  - 甲烷产生增加
  - 外源有机碳矿化受抑制（外源碳在厌氧条件下更难降解）
  - 有机碳埋藏效率提高，但CH₄排放增加

**光降解：**
- 更长的分层使表层CDOM充分光降解
- 深水层CDOM免受光照→光降解与暗矿化耦合关系复杂

### 3.7 湖泊分布的未来变化

利用IPCC B1情景和CCSM气候模式，预测**2009–2050年**湖泊变化：

| 区域 | 径流变化 | 湖泊数量变化 |
|------|---------|-------------|
| 北极/亚北极 | 增加 | 湖泊大幅增加（冻土融化形成热喀斯特湖） |
| 北方针叶林带 | 增加 | 湖泊增加，海狸筑坝增加 |
| 温带 | 减少 | 湖泊显著减少（北美洲、西欧、亚洲） |
| 热带 | 区域不均 | 高异质性 |

全球天然湖泊总面积至2050年变化不大，但区域分布将显著改变。

同时，水库面积将以每年**1–2%** 的速度增长，从约40万 km²增至 **~100万 km²**（2050年），约为天然湖泊面积的1/4。

### 3.8 不同气候带的变化预测

**北极地区：**
- 永久冻土融化→大量土壤碳（占全球土壤碳1/3以上）进入水体
- 热喀斯特湖形成加速
- CO₂和CH₄排放显著增加

**北方地区：**
- 降水增加→DOC浓度升高→矿化、埋藏和排放均增强
- 但径流增加→停留时间缩短→在湖内处理的比例下降
- 海狸活动增加可能进一步改变水文

**温带地区：**
- 径流减少→湖泊面积减小、数量减少
- 蒸发浓缩→DOC浓度升高但严重光漂白→颜色降低
- 富营养化加剧→自生生产力提高→有机物埋藏增加
- 分层延长→底层缺氧加剧→CH₄产生增加

**热带地区：**
- 水库建设加速
- 高温促进微生物代谢→更多DOC被呼吸
- 高温加剧缺氧→CH₄产生增加
- 水库建设可能是气候变化的重要正反馈过程

## 四、两篇文章的贡献与演进

### 4.1 Cole et al.（2007）的开创性贡献

1. 首次系统构建了内陆水体的全球碳收支框架
2. 明确提出并验证了"活性管道"概念
3. 证明内陆水体虽然面积小，但单位面积碳通量显著高于陆地
4. 强调陆地NEP中被"隐藏"的横向碳损失

### 4.2 Tranvik et al.（2009）的推进

1. 更新了全球湖泊面积和数量估算（基于Downing et al., 2006）
2. 大幅提高了内陆水体碳通量估算值
3. 引入溪流碳通量（Battin et al., 2008）
4. 纳入盐湖CO₂排放（~0.11–0.15 Pg C yr⁻¹）
5. 系统探讨了气候变化对湖泊碳循环的反馈机制
6. 首次定量预测了湖泊分布的未来变化
7. 提出可监测和管理的适应性策略

### 4.3 通量估算的演进：Cole → Tranvik



从2.1倍于海洋输出（Cole）到3.2倍于海洋输出（Tranvik），显示出内陆水体在碳循环中的重要性认识不断增强。

## 五、研究展望与未解决问题

两篇文章共同指出的关键未知领域：

1. **小型溪流的全球贡献**：源头溪流pCO₂高但面积数据缺失
2. **洪泛区与湿地的边界**：介于水陆之间的过渡带难以纳入统一框架
3. **地下水的碳通量**：体积巨大但其碳循环角色知之甚少
4. **盐湖**：占内陆水体近一半水量，但碳收支研究极度匮乏
5. **水库的长期效应**：大坝寿命短，沉积物碳的最终归宿不明
6. **人为变化的定量归因**：土地利用变化、富营养化、大坝建设如何改变通量？
7. **碳埋藏的"净"效应**：内陆水体增加的埋藏是否只是陆地碳的重新分配？
8. **CH₄排放的精确量化**：气泡排放（ebullition）和植物介导排放的测量方法学限制
