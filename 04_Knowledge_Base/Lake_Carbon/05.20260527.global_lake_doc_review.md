# 全球内陆湖泊溶解性有机碳（DOC）遥感—时空变化—环境驱动—碳循环体系：综合研究综述

## 摘要

内陆湖泊溶解性有机碳（Dissolved Organic Carbon, DOC）是水生生态系统中最大的活性有机碳库，在湖泊生态功能、全球碳循环和气候变化中扮演着枢纽角色。DOC 可占湖泊总有机碳的 90% 以上，其浓度与组成调控着水体光学特性、初级生产力、微生物代谢以及温室气体（CO₂、CH₄）的产生与排放。全球内陆水域每年处理约 5.1 PgC 的陆地来源有机碳（Drake et al., 2018），CO₂ 排放量 1.07–3.9 PgC yr⁻¹（Raymond et al., 2013; DelSontro et al., 2018），CH₄ 排放量约 37–156 Tg CH₄ yr⁻¹（Rosentreter et al., 2021），合计温室气体排放当量与全球农业排放量可比。本文从遥感反演方法、时空变化格局、环境驱动机制和碳循环贡献四个维度，系统综述了全球内陆湖泊 DOC 研究的最新进展。遥感方面，Landsat 8/9 OLI、Sentinel-2 MSI 与 MODIS 等多源卫星结合机器学习算法（随机森林、支持向量回归、极端学习机）已实现从局部到全球尺度的 DOC/CDOM 反演，GLORIA 数据集（7,572 条高光谱测量）和 HLS V2.0 虚拟星座为算法开发提供了关键支撑。时空格局方面，近数十年北方湖泊普遍出现"褐化"（browning）现象，但趋势在空间上高度异质，某些湖泊同时存在"复蓝"趋势。驱动机制方面，酸沉降恢复、气候变化（升温、降水极端化）、土地利用变化和永冻土退化是主要调控因子。碳循环方面，湖泊 DOC 通过微生物矿化-光降解耦合过程转化为 CO₂/CH₄ 排放，构成气候反馈正循环。最后，本文识别了当前研究的五个关键知识缺口，并展望了星载高光谱、AI 模型与全球联网观测融合的未来方向。

**关键词**：溶解性有机碳；内陆湖泊；遥感反演；时空变化；环境驱动；碳循环；气候变化；CDOM

## 1 引言：DOC 在湖泊、地球碳循环与气候变化中的枢纽地位

### 1.1 DOC 的定义与生态重要性

溶解性有机碳（DOC）是指能通过 0.2–0.7 μm 滤膜的那部分有机碳，是溶解性有机质（DOM）的碳含量度量（Hansell & Carlson, 2015）。在湖泊生态系统中，DOC 占水体总有机碳（TOC）的 50–90%，是最大的活性有机碳库（Zhou et al., 2025）。DOC 通过以下机制深刻影响湖泊生态功能：

1. **光调控**：有色溶解性有机质（CDOM）强烈吸收紫外-蓝光波段，决定水下光场的强度与光谱组成，进而调控初级生产力（Thrane et al., 2014）和 UV 辐射防护（Boily, 2012）。
2. **能量流动**：DOC 是异养微生物的主要能量底物，驱动"微生物环"（microbial loop）中的碳流，支撑经典食物链（Cole et al., 2006）。
3. **生物可利用性**：DOC 的化学组成（芳香性、分子量分布）决定其生物降解性，直接影响湖泊的代谢状态（净自养/异养）（Lapierre et al., 2013）。
4. **水质指标**：DOC 浓度升高导致水体褐化（browning），影响饮用水处理中的消毒副产物前体物浓度（Swinamer et al., 2024）。

### 1.2 DOC 在全球碳循环中的核心地位

内陆水域（湖泊、水库、河流）虽然仅占地球非冰川陆地面积的 3.7%，却是全球碳循环的热点区域（Cole et al., 2007; Tranvik et al., 2009）。最新的全球估算表明：
- 内陆水域每年接收和处理约 **5.1 PgC** 的陆地来源有机碳（Drake et al., 2018）；
- 湖泊 CO₂ 排放通量达 **1.07–3.9 PgC yr⁻¹**（Raymond et al., 2013; DelSontro et al., 2018）；
- 湖泊/内陆水域 CH₄ 排放约 **37–156 Tg CH₄ yr⁻¹**，占总自然 CH₄ 排放的显著部分（Rosentreter et al., 2021）；
- DOC 构成了这一庞大碳通量的主要载体——在大多数湖泊中，DOC 是有机碳库的主导形态（Zhou et al., 2025）。

DOC 通过三种主要途径参与全球碳循环：（1）**侧向输送**——将陆地碳通过河流-湖泊系统向海洋转移，构成陆地-海洋碳输送的关键纽带；（2）**垂直排放**——通过微生物降解与光化学矿化将 DOC 转化为 CO₂ 和 CH₄ 排放到大气中；（3）**沉积埋藏**——部分 DOC 通过絮凝-沉降进入沉积物，实现长时间尺度的碳封存。

### 1.3 DOC 对气候变化的敏感性与反馈

DOC 对气候变化高度敏感，表现在三个层面：
- **气候变暖**直接加速微生物对 DOC 的降解速率（Q₁₀ ≈ 2–3），增加 CO₂ 排放（Gudasz et al., 2010）；
- **降水格局变化**改变陆地-湖泊 DOC 输送通量——极端降水事件可引起 DOC 脉冲式输入（Zhou et al., 2025），干旱则减少输送；
- **永冻土退化**释放大量古老 DOC，其高生物降解性可能引发强烈碳排放（Abbott et al., 2014; Fristensky & Carey, 2026）。

上述机制共同构成了一个潜在的气候正反馈循环：**气候变暖 → DOC 输入/降解增加 → CO₂/CH₄ 排放增加 → 进一步气候变暖**。量化这一反馈的强度是全球碳循环研究面临的核心挑战之一。

### 1.4 本文目标与结构

本文旨在系统综述全球内陆湖泊 DOC 研究的四个相互关联的维度：（1）**遥感反演方法**——多源卫星数据与 AI 如何实现大尺度 DOC 监测；（2）**时空变化格局**——不同气候区和时间尺度上 DOC 的演化特征；（3）**环境驱动机制**——气候、水文、土地利用和地球化学因子的调控机理；（4）**碳循环贡献**——DOC 在整个地球系统中的归宿与气候反馈。每个维度均以 DOC 的枢纽地位为主线贯穿论述。

## 2 湖泊 DOC 遥感反演理论与方法

### 2.1 反演理论基础：CDOM 作为光学代理

DOC 本身并不具备光学活性，无法直接被卫星传感器探测。其遥感反演依赖于一个关键的光学桥梁——**有色溶解性有机质（CDOM）**，也称为 gelbstoff 或黄色物质（Blough & Del Vecchio, 2002）。CDOM 是 DOM 中能吸收紫外-可见光的组分，其吸收光谱在 400–700 nm 范围内呈现典型的指数衰减形式：

$$a_{CDOM}(\lambda) = a_{CDOM}(\lambda_0) \cdot e^{-S(\lambda - \lambda_0)}$$

其中 $a_{CDOM}(\lambda)$ 为波长 λ 处的吸收系数，$S$ 为光谱斜率。由于 DOC 与 CDOM 在大多数内陆水体中存在显著的相关性（r² ≈ 0.60–0.90），可以通过遥感获取的水体反射率反演 CDOM，进而估算 DOC 浓度（Chen et al., 2024; Murphy et al., 2025）。

Zhang et al.（2021）在《Science of the Total Environment》的综述中指出，CDOM 的遥感反演已成为连接水色遥感和碳循环研究的核心桥梁。ARIX 等新型荧光指数已实现对 DOC 芳香性和分子量的预测，提高了间接反演的精度（Murphy et al., 2025）。

### 2.2 卫星传感器与数据源

#### 2.2.1 中分辨率多光谱传感器

当前湖泊 DOC/CDOM 遥感主要依赖以下传感器：

| 传感器 | 空间分辨率 | 重访周期 | 波谱范围 | 关键优势 |
|--------|-----------|---------|---------|---------|
| Landsat 8/9 OLI | 30 m | 16 d | VNIR-SWIR | 34 年连续存档 |
| Sentinel-2 MSI | 10–20 m | 5 d | VNIR-SWIR (+红边) | 高时空分辨率 |
| MODIS (Aqua/Terra) | 250–1000 m | 1–2 d | VNIR-SWIR | 高时间频率 |
| MERIS (Envisat) | 300 m | 3 d | VNIR | 2002–2012 历史存档 |
| GOCI (COMS) | 500 m | 1 h (8次/天) | VNIR | 静止轨道高频观测 |

Landsat 系列提供了最长的连续时间序列（1984 年至今），被广泛用于长期趋势分析。Sentinel-2 以较高的时空分辨率（5 天/10–20 m）在近年来迅速成为主流。在长江口水域的一项比较研究表明，Landsat OLI 在 DOC/CDOM 反演中取得了优于 Sentinel-2 MSI 的表现（决定系数 R² = 0.70 vs 0.65），主要归因于其更高的辐射定标精度（Chen et al., 2024）。

#### 2.2.2 Harmonized Landsat Sentinel (HLS) 虚拟星座

NASA 的 HLS 项目（Ju et al., 2025, *Remote Sensing of Environment*）将 Landsat 8/9 OLI 与 Sentinel-2 MSI 融合为统一的 30 m 分辨率 NBAR（双向反射分布函数归一化反射率）数据集。HLS V2.0（2025 年发布）提供 2013 年至今的近全球覆盖，大气校正与 BRDF 校正算法获得显著改进。这一虚拟星座将有效重访频率提升至 **2–3 天**，为湖泊 DOC 监测提供了前所未有的时间分辨率（NASA Science, 2025）。

#### 2.2.3 GLORIA 全球原位参考数据集

Pahlevan et al.（2023, *Scientific Data*）建立的 GLORIA（GLObal Reflectance community dataset for Imaging and optical sensing of Aquatic environments）数据集是当前最全面的内陆-海岸水体高光谱原位数据库，包含 **7,572 条高光谱遥感反射率测量**（350–900 nm），覆盖不同光学水体类型。每条测量至少配准一项水质参数（叶绿素-a、总悬浮物、CDOM 吸收系数、Secchi 深度）。GLORIA 的发布极大地推动了全球尺度水质遥感算法的验证与比较。

### 2.3 反演算法：从经验回归到机器学习

#### 2.3.1 传统经验与半分析方法

早期的 DOC/CDOM 反演主要采用波段比值模型，利用蓝绿波段反射率比值或特定波段反射率与 CDOM 吸收系数的经验关系（Kutser et al., 2005; Zhu et al., 2014）。此类方法在特定湖泊中表现良好，但跨区域移植能力有限。半分析模型（如 QAA 算法）通过生物光学模型分离水体各组分的吸收和散射贡献，理论上更具普适性，但对大气校正精度要求极高（Lee et al., 2002）。

#### 2.3.2 机器学习方法

近年来，机器学习方法在 DOC 遥感反演中展现出显著优势：

- **随机森林回归（RFR）**：在融合 HLS 数据的全球水质预测中取得了 BOD 的决定系数 R² = 0.68（ELM 则达 0.70）（Zhou et al., 2023, *Remote Sensing*）。
- **支持向量回归（NuSVR）**：在基于 GOCI 的长江口 DOC 反演中，NuSVR 准确反演出 CDOM 吸收光谱（aCDOM(300) MAPD = 32%, S275-295 MAPD = 8.6%），进而实现 DOC 反演，验证集 MAPD = 11%，卫星验证 MAPD = 14%（Chen et al., 2024）。
- **极端学习机（ELM）**：单一隐含层前馈神经网络，训练速度快，在全局水质预测中表现优异（Zhou et al., 2023）。
- **高斯过程回归（GPR）**：提供预测不确定性的概率估计，适用于复杂的山地湖沼系统（Ayala Izurieta et al., 2022）。

#### 2.3.3 物理-数据融合趋势

最新研究趋势是将物理模型的知识（如辐射传输理论）嵌入机器学习框架，形成"物理引导的机器学习"（physics-informed ML）范式。例如，利用辐射传输模型生成大量训练数据，再以迁移学习适应特定湖泊的光学条件，从而缓解小样本问题。

### 2.4 当前挑战与前沿方向

1. **大气校正**：内陆水体的邻近效应和气溶胶异质性对大气校正构成严峻挑战，尤其在小型湖泊（<1 km²）中，邻近陆地像元的信号污染（adjacency effect）可导致反射率误差达 50% 以上。
2. **DOC-CDOM 关系的不确定性**：DOC 与 CDOM 的比值在不同湖泊和季节中变化显著，受 DOM 来源（外源 vs 内源）、光降解和微生物加工的影响（Murphy et al., 2025）。这构成了 DOC 遥感反演的根本性瓶颈。
3. **非光学活性参数的挑战**：DOC 本质上为非光学活性参数（nOAC），需要依赖与 CDOM 的统计学关系。Zhou et al.（2023）的研究表明，全球模型中 nOAC 的预测精度（R² ≈ 0.43–0.68）系统性地低于光学活性参数（如叶绿素-a）。
4. **高光谱卫星的机遇**：即将到来的 NASA SBG（Surface Biology and Geology, 2028+）和 ESA CHIME（Copernicus Hyperspectral Imaging Mission）将提供 30 m 分辨率、10–15 nm 光谱间隔的高光谱数据，有望突破 CDOM 组分识别的分辨率限制。

## 3 全球湖泊 DOC 时空变化格局

### 3.1 湖泊褐化：北方湖泊的普遍趋势

过去数十年，欧洲、北美和西伯利亚的北方湖泊普遍出现 DOC 浓度上升和水色加深的现象，即"湖泊褐化"（lake browning）（Monteith et al., 2007; Meyer-Jacob et al., 2019; Rodríguez-Cardona et al., 2023）。Rodríguez-Cardona et al.（2023, *Communications Earth & Environment*）在加拿大魁北克省的长序列观测发现：

- **DOC 趋势总体呈上升**，但变化速率高度异质（0.1–2.5% yr⁻¹）。
- **DOC、水色和 CO₂ 三者间的耦合程度取决于湖泊水滞留时间**；短滞留时间的湖泊表现出更强的耦合，说明陆源有机碳的主导作用。
- 最高的色度和 CO₂ 变化率出现在 DOC 增长最快的湖泊中。

Meyer-Jacob et al.（2019, *Scientific Reports*）进一步发现，湖泊褐化经历了两个阶段：1970–1990 年代的"褐化"（acid deposition-induced）和 1990 年代后酸沉降恢复导致的"复褐化"（re-browning），说明驱动因素的阶段性变化。

### 3.2 空间异质性：不同气候带的差异

全球湖泊 DOC 的时空格局呈现显著的气候带分异：

- **寒带/亚寒带湖泊**：DOC 浓度最高（10–50 mg L⁻¹），受永冻土退化和泥炭地排水强烈影响（Fristensky & Carey, 2026; Abbott et al., 2014）。
- **北方森林湖泊**：褐化趋势最明显，主要受酸沉降恢复和气候变暖的叠加驱动（Zhu et al., 2024）。
- **温带湖泊**：趋势较复杂，还受土地利用（农业扩张、城市化）的强烈调控。
- **热带/亚热带湖泊**：研究严重不足。季风区的暴雨事件可引发 DOC 脉冲式输入，显著影响湖泊碳排放（Zhou et al., 2025）。
- **青藏高原湖泊**：作为"亚洲水塔"，其 DOC 变化对区域碳收支有重要意义，但遥感监测受高海拔大气校正困难限制。

Ren et al.（2025, *ESSD*）构建了全球土壤 DOC 数据库（12,807 条数据），发现全球土壤 DOC 浓度范围为 0.04–7,859 mg kg⁻¹，均值 222.78 mg kg⁻¹。海拔、黏粒含量和土壤有机碳是最重要的预测因子。这意味着土壤 DOC 的时空变化通过侧向输送通道直接塑造着湖泊 DOC 格局。

### 3.3 年际到年代际趋势

Wang et al.（2021, *Scientific Data*）利用 MODIS 数据建立了 2000–2018 年全球大型湖泊 Forel-Ule 水色指数时间序列，发现全球湖泊水色在 19 年间经历了系统性的变化，与气候因子和人类活动显著相关。

美国 USGS 的 LAGOS-US LANDSAT 数据集（Hanly et al., 2025, *Scientific Data*）提供了 1984–2020 年共 37 年的全美湖泊水质遥感估算结果（湖泊 ≥ 4 ha），采用机器学习模型将 Landsat 与地面监测数据（Water Quality Portal）融合，使年代际趋势分析成为可能。

### 3.4 空间异质性的来源

Zhu et al.（2024, *Water Resources Research*）在瑞典 13 个嵌套的北方集水区中发现：

- 所有集水区在 2003–2021 年间均呈现 DOC 上升趋势，但响应速率相差 **5 倍**。
- **无单一机制能完全解释褐化**：硫酸盐沉降恢复是长期增长的主要驱动力，其次是陆地生产力上升、温度和流量增加。
- 集水区面积和土地覆盖类型调节了 DOC 对驱动因子的响应速率。
- 值得注意的是，褐化速率在过去十年已有所减缓——硫酸盐恢复基本完成后，其他驱动因子不足以维持长期增长。

## 4 环境驱动机制

### 4.1 气候驱动：温度与降水

#### 4.1.1 温度效应

温度通过多种途径影响湖泊 DOC 动态：
- **直接加速降解**：微生物 DOC 降解的 Q₁₀ 约为 2–3，温度升高直接提升 CO₂ 产率（Gudasz et al., 2010）。
- **延长生长季节**：气候变暖延长了陆域植被生长季和土壤微生物活动期，增加了向水体的 DOC 输送（Finstad et al., 2016）。
- **热分层效应**：升温增强湖泊热稳定性，延长底层缺氧时间，促进 CH₄ 产生。

#### 4.1.2 降水与极端事件

降水的量和强度调控 DOC 的陆地-水体输送通道。Swinamer et al.（2024, *Environmental Science & Technology*）在加拿大新斯科舍省的研究表明：
- 2023 年干旱春季后接温暖湿润夏季，水源地 NOM（以水色计）骤升 **>67%**。
- 为应对 NOM 升高，混凝剂（明矾）用量几乎翻倍，其碳排放（CO₂ eq）增加 3–7 倍。
- 这一案例揭示了气候变化对 DOC 调控以及相关人类（水处理）和气候（碳排放）后果的级联效应。

Zhou et al.（2025, *PMC*）指出，季风区暴雨引发的 DOC 脉冲输入是驱动湖泊碳排放的关键但被低估的因素。暴雨将富含脂肪族化合物的污水/土壤 DOM 快速输送入湖，其高生物降解性导致水体快速缺氧，促进 CO₂ 和 CH₄ 的产生。

### 4.2 酸沉降恢复

Monteith et al.（2007, *Nature*）的里程碑研究首次建立了酸沉降下降与 DOC 上升之间的因果关系：随着硫酸盐沉积减少，土壤 pH 回升，有机质溶解度增加，导致湖泊 DOC 浓度显著上升。这一机制被认为是 1970–2010 年间北方湖泊褐化的首要驱动因子。Zhu et al.（2024）的归因分析进一步确认，尽管降硫是长期趋势的主因，其相对重要性已逐渐下降，气候因子的作用比例在增加。

### 4.3 永冻土退化

永冻土区储存着约 1,400–1,600 PgC 的有机碳，是其上湖泊 DOC 的主要来源。气候变暖导致永冻土活动层加深甚至彻底退化，释放的古老 DOC 具有较高的生物降解性（30–80% 在数周内矿化）（Abbott et al., 2014）。Fristensky & Carey（2026, *JGR-Biogeosciences*）在加拿大育空地区的研究表明：
- 积雪量通过控制春季流量和景观连通性，是年际 DOC 变化的关键因素。
- 高雪-高流量年份的 DOM 更为古老、芳香性更高。
- 景观特征（湖泊密度、湿地比例、永冻土覆盖度）主要影响夏季 DOM 质量。

### 4.4 土地利用与人类活动

农业和城市化显著改变湖泊 DOC 浓度与组成。农业流域输入的富含养分的 DOC 刺激内源初级生产，改变 DOC 的来源结构（从外源腐殖质向内源蛋白质类转变）。Beaulieu et al.（2020, *JGR-Biogeosciences*)）发现流域农业用地比例是水库 CH₄ 排放的第二重要预测因子，支持了 DOC→微生物→CH₄ 的级联逻辑。

## 5 湖泊 DOC 与碳循环

### 5.1 内陆水域碳收支

Cole et al.（2007）的开创性工作首次将内陆水域整合进全球碳循环框架，提出了"管道-反应器"（pipe-reactor）概念模型——湖泊既是将陆地碳输送至海洋的管道，也是对碳进行生物/化学加工的反应器。

最新的全球碳收支估算（Zhou et al., 2025; Rosentreter et al., 2021）表明：
- 湖泊和内陆水域处理 **5.1 PgC yr⁻¹** 的陆地有机碳输入。
- CO₂ 排放通量：**1.07–3.9 PgC yr⁻¹**（低值为大型水库纳入后的修正值，高值为传统估计）。
- CH₄ 排放通量：**37–156 Tg CH₄ yr⁻¹**（Rosentreter et al., 2021），采用 IPCC AR6 GWP（非化石来源 27.0），相当于 ~1.0–4.2 PgCO₂eq yr⁻¹。
- 将两者合并，内陆水域的温室气体排放当量可与全球农业温室气体排放量相比较。

### 5.2 DOC 矿化与温室气体产生

DOC 通过两条主要途径转化为温室气体：

1. **微生物矿化**：异养细菌通过呼吸作用将 DOC 转化为 CO₂（好氧条件）或 CO₂ + CH₄（厌氧条件）。湖泊沉积物是 DOC 降解和 CH₄ 产生的主要场所。全球 CH₄ 排放的约 50–60% 来自湖泊沉积物（DelSontro et al., 2018）。

2. **光化学矿化**：紫外辐射直接裂解大分子 DOC 为小分子化合物，部分直接转化为 CO₂（光矿化），部分增加 DOC 的生物可利用性（光增产），间接促进后续微生物降解。

两种途径的耦合——光化学过程改变 DOC 分子结构后加速微生物分解——是自然水体中 DOC 最终矿化的主导路径。

### 5.3 富营养化湖泊的特殊角色

富营养化湖泊在全球碳循环中扮演着独特而矛盾的角色。中国 43 个富营养化湖泊的调查（2024, *Ecological Indicators*）发现：
- _p_CO₂ 范围 0.9–1,366.4 μatm，均值 356.9 ± 310.3 μatm。
- **69.3% 的采样点 CO₂ 不饱和**（表现为碳汇），证明富营养化条件下初级生产固碳可能超过异养呼吸。
- 中国富营养化湖泊整体表现为弱源到弱汇（-0.7 至 1.0 Tg C a⁻¹）。
- CO₂ 的源-汇转换功能受湖泊形态（面积、深度）和气候带（降水梯度）的调控。

### 5.4 气候反馈与模型参数化挑战

DOC 驱动的气候反馈机制是当前研究的最大不确定性来源之一。Yang et al.（2025, *ESSD*）首次提出了土壤 DOC 向河流 DOC 转化的速率参数 Pr 的定量框架，发现 Pr 受气候、水文和地质因素的联合控制，其空间异质性远高于当前地球系统模型的默认参数化方案。

**GHG-depths 数据集**（2026, *Scientific Data*）整合了全球 522 个湖泊（38 个国家）的深度剖面 CO₂ 和 CH₄ 测量数据（2,558 次采样事件），首次实现了底部水体过程对碳排放贡献的全球尺度评估。该数据集将显著改善地球系统模型对湖泊温室气体排放的预测能力。

## 6 知识缺口与未来方向

### 6.1 当前研究的五个关键缺口

1. **全球观测覆盖不均衡**：北方湖泊研究密集，而热带、亚热带和干旱区湖泊几乎空白；小湖泊（<1 km²）的遥感监测受空间分辨率限制。
2. **DOC-CDOM 关系的不确定性**：不同湖泊间 DOC:CDOM 比值的时空变异尚未被充分约束，制约了 DOC 遥感的定量精度。
3. **极端事件的碳效应**：暴雨、洪水、干旱、野火等极端事件对湖泊 DOC 和碳排放的触发效应缺乏系统评估。
4. **地下水的 DOC 输入**：地下水向湖泊的 DOC 输送通量几乎完全未知，可能在湖泊碳收支中占重要比例。
5. **长期地球系统整合**：DOC 动态（尤其是永冻土退化释放的古老碳）尚未被充分纳入 CMIP 级地球系统模型。

### 6.2 方法学前沿

- **星载高光谱**：NASA SBG（2028）和 ESA CHIME 将提供 10–15 nm 光谱间隔的数据，有望实现 CDOM 亚组分（如类腐殖质、类蛋白质）的区分，从而突破 DOC 反演精度瓶颈。
- **AI 基础模型**：基于图神经网络和 Transformer 架构的跨区域迁移学习方法，可有效利用稀疏现场观测数据。
- **全球联网观测**：整合 FLUXNET 理念的湖泊碳通量观测网络（如 LakeTEC）、GLORIA 式光谱数据库和卫星遥感的"三级观测体系"。

### 6.3 政策与管理的启示

湖泊 DOC 动态的直接政策联系包括：（1）饮用水处理成本因褐化上升（Swinamer et al., 2024）；（2）水库温室气体排放纳入国家清单的紧迫性（Beaulieu et al., 2020）；（3）湖泊碳汇功能在碳交易市场中的潜在价值。

---

## 7 结论

全球内陆湖泊 DOC 集"生态调控者"、"碳输送载体"和"气候反馈放大器"三重角色于一身。遥感技术（从 Landsat 到高光谱卫星）与人工智能的融合已使从空间监测湖泊 DOC 成为现实，但仍面临 DOC-CDOM 关系不确定性、大气校正和跨区域移植等挑战。湖泊 DOC 经历了北方湖泊系统性褐化到区域异质性增强的时空演变，这一格局受酸沉降恢复、气候变暖/极端化、永冻土退化和土地利用的共同驱动。DOC 通过微生物矿化和光化学途径转化为 CO₂/CH₄ 排放，使内陆水域成为全球碳收支中不可忽视的组成部分——全球内陆水域处理 ~5.1 PgC yr⁻¹ 陆地有机碳输入，释放 1.07–3.9 PgC yr⁻¹（CO₂）和 37–156 Tg CH₄ yr⁻¹。在气候变化的背景下，DOC 驱动正反馈循环的强度是当前研究面对的核心未知量。星载高光谱革命、AI 基础模型和全球联网观测有望在未来十年显著推进对这一关键枢纽变量的理解。
