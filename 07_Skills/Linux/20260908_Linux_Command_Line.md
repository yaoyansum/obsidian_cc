# Linux命令行常用操作

## 文件操作

```bash
ls          # 列出文件
cd          # 切换目录
pwd         # 显示当前路径
mkdir       # 创建目录
rm          # 删除文件/目录
cp          # 复制
mv          # 移动/重命名
touch       # 创建空文件
```

## 文本处理

```bash
cat         # 查看文件内容
grep        # 搜索文本
awk         # 文本处理
sed         # 流编辑
head/tail   # 查看文件前/后几行
wc          # 统计行数/字数
```

## 权限与用户

```bash
chmod       # 修改权限
chown       # 修改所有者
sudo        # 超级用户执行
```

## 进程管理

```bash
ps          # 查看进程
top         # 实时监控
kill        # 终止进程
```

## 网络

```bash
curl        # HTTP请求
wget        # 下载文件
ssh         # 远程连接
```

## 系统

```bash
df          # 磁盘空间
du          # 目录大小
free        # 内存使用
```
