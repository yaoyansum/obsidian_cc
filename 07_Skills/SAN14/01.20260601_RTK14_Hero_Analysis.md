# 三国志14 主要战力人物个人特点与连携一览

> 聚焦各势力主力战斗武将的个人特点、五维优势、个性、战法及连携关系。

## S级 — 神中神

### 关羽

| 项目 | 内容 |
|------|------|
| 统率/武/智/政/魅 | 96 / 97 / 75 / 62 / 93 |
| 定位 | 物理输出核、团队轴心 |
| 擅长 | **野战 > 攻城** — 军神AOE最适合野战群殴，搭关家军连携可兼任攻城 |
| 关键个性 | **军神**（范围内提升自部队攻防+敌方异常成功率）、**一骑**（单挑优势） |
| 独有战法 | **军神** — 范围AOE高伤，接友军连携可达单体1.25倍×N |
| 连携网 | 刘备（义兄弟3级）、张飞（义兄弟3级）、周仓（双亲2级）、关平（血缘2级）、关银屏（血缘+双亲3级）、赵累（单亲1级）、关兴（血缘2级）、张辽（跨势力亲爱）、徐晃（跨势力亲爱） |
| **优势总结** | 全游戏唯一S级。五维无短板，武力极高能单挑；军神联动带动整个关家军；可拆3队仍保持连携。怕断粮，需配方圆/鱼鳞阵 |
