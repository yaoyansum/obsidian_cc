# 三国志14 武将连携关系与组队攻略

## 连携机制说明

### 连携等级
- **1级（单亲/单箭头）**：单方面亲爱，联动概率较低
- **2级（双亲/双箭头）**：双相亲爱，联动概率高
- **3级（血缘+双亲）**：血缘默认1级 + 双亲2级 = 3级，联动概率最高

其中义兄弟与双亲的联动威力相同。

### 连携效果
- 相邻武将不论单亲/双亲，属性加成相同
- 联动战法威力约为单人战法的 **1.25倍**，且附加异常状态
- 连携等级不影响战法威力，只影响触发概率
- 亲密加成只影响普通攻击，不影响战法输出

## 蜀国（刘备势力）

### 核心组队方案

#### 1. 刘关张核心组
- 刘备、关羽、张飞（义兄弟）
- 适合大会战，但251剧本中刘备可单独带队

#### 2. 关家军（可拆为3队）
| 队伍   | 成员                 | 特点             |
| ---- | ------------------ | -------------- |
| 关家主力 | 关羽 + 周仓 + 关银屏 + 赵累 | 军神核心，有血战、束缚、林战 |
| 关家二队 | 关平 + 廖化 + 关索       | 联动充足           |
| 义兄弟队 | 关兴 + 张苞（义兄弟）       | 可作为防守点或3线进攻    |

> 关家军缺点：不与任何一线谋士有联动。建议配徐庶或庞统作混乱/攻城将。

#### 3. 黄忠组
- 黄忠 + 法正 + 严颜
- 法正有冲车，配合黄忠破城极强
- 注：法正本人不与严颜有直接关系

#### 4. 诸葛亮组
- 诸葛亮 + 张飞 + 庞统 + 徐庶
- 除诸葛亮与张飞非双亲外，其余均为双亲
- 考验微操但威力极强

#### 5. 马家军（需汉中剧本）
- 马超 + 马腾 + 马休 + 马铁 + 马云騄 + 韩遂
- 全3级联动（血缘1级+双亲2级）
- 超强六芒星连携

#### 6. 山战小组
- 吴毅 + 张嶷 + 某人（山战3人组）
- 王平 + 某人（山战2人组）
- 魏延 + 陈式（山战2人组）

#### 7. 其他组合
- 姜维 + 钟会（双亲）：强力防守点
- 刘备：万金油，谁都适合搭配

## 连携机制核心结论

1. **单亲/双亲都会联动**，单亲概率低，双亲概率高，与谁亲谁无关
2. **属性加成**不分单亲双亲，相邻即生效
3. **义兄弟与双亲**联动威力相同
4. **血缘默认1级**，有单亲变2级，血缘+双亲变3级
5. **联动战法威力≈1.25倍单人**，带异常状态
6. **亲密加成只影响普攻**，不影响战法输出
