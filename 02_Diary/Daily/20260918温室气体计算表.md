
# 准备

- 2g KCl
- 5 mg N2
- 三个空白瓶，气密性
- 气瓶重量

# 气相气体浓度测量
- 获得标气峰面积（相对值）和标气中气体浓度（绝对值）
- 测量样品上层气体浓度峰面积
- 比值，得到气相浓度*Cgas*

| 记录项                          | 含义                       | 注释  |
| :--------------------------- | :----------------------- | --- |
| 空重 F                         | 顶空瓶 + KCl 空瓶重量（g）        |     |
| 湿重 H                         | 注入水样后称重（g）               |     |
| **Vwater = H − F**           | 注入水样的体积（mL，按 1 g/mL 计）   |     |
| Vbottle = 35.45 mL           | 顶空瓶总体积                   |     |
| **Vhead = Vbottle − Vwater** | 顶空气相体积   35.45ml    15ml |     |
| Vplus                        | 注射器顶出的气体体积               |     |
| Tae / Pe                     | 实验室温度（℃) / 气压（hPa)，取多次平均 |     |
| Tws / Cond                   | 实测水温（℃) / 电导率（μS/cm)     |     |
| Salinity                     | 盐度                       |     |

# 气相浓度 推导 水体浓度

## *Vm*气相摩尔体积 (L/mol)

![[file-20260918110126367.png]]

- *Vme* 是**瓶内实际压力**下的摩尔体积——注水把气体从 Vtotal 压缩到 Vhead，瓶内压 = Pe×(Vhead+Vplus)/Vhead；
- *Pe* 为实验室测量气压hPa；
- *Vms*  Pe通过ERA5顺势数据匹配。
