# KTF‑BC 论文核函数（Kernel）问答整理

> 论文来源：`1-s2.0-S0034425726000234-main.pdf`（Remote Sensing of Environment）
> 方法：基于核的时间填充 + 偏差校正（Kernel-based Temporal Filling + Bias Correction, KTF‑BC）
> 用途：全天气近地表气温（Ta）重建

---

## 1. 核函数的作用

该研究提出**基于核的时间填充方法（KTF）**，使用**季节核（seasonal kernel）**与**局部核（local kernel）两个高斯核函数**，共同为参考日分配权重，实现云污染像元**理论晴空近地表气温（Ta）**估算。

### 1.1 季节核 K_seasonal
- 捕捉气温**年周期季节变化规律**，依据年积日（DOY）计算目标日与参考日的季节相似度；对年积日越接近的观测赋予更高权重，还可跨多年提取同物候期样本。
- 带宽参数控制权重衰减速度；当云持续时间很长、有效观测稀少时，依靠季节核提供气候态基准，保障长时间云覆盖区域的填充稳定性。

### 1.2 局部核 K_local
- 刻画气温**短期时序波动**，按照实际日时间距离衡量相似度，距离目标日期越近，权重越高。
- 可以捕捉寒潮、热浪等短时天气带来的快速气温变化，在局部有效观测充足时，优先反映短期温度动态变化。

### 1.3 动态融合权重系数 α
两个核函数结果通过自适应系数 α 加权融合得到最终权重 w_ij：

> **w_ij = α · K_seasonal + (1−α) · K_local**

- 观测充足、气温短时变化剧烈：增大局部核比重，优先响应短期温度波动；
- 观测稀疏、短期变化平缓：提升季节核贡献，依靠季节周期保证估算可靠。

### 1.4 核函数整体价值
1. 输出权重用于加权平均，计算云覆盖像元的**理论晴空气温 T_theo**，完成第一步时序缺口填充；
2. 高斯核平滑衰减特性，避免权重突变，数值稳定性好；
3. 兼顾**年际季节周期**和**短期天气波动**，相比单一时间插值，同时适配多云长期缺测、短时天气扰动两类场景；
4. 输出的理论晴空气温，作为后续偏差校正模块的输入基础，为整套 KTF‑BC 全天候气温重建提供初始时序填充结果。

> **注意**：KTF 输出只是**理论晴空气温**，并非真实多云条件气温，后续还需机器学习偏差校正步骤，修正云致降温带来的系统高估。

## 2. 核的作用维度与带宽大小

### 2.1 作用维度：只在时间维度起作用，不做空间卷积

KTF 的核函数是**时间核（时序核）**，**不在空间上滑动，不利用周边像元空间信息**，只对**同一个像元自身的时间序列**做加权插值填充云缺失值。

- 季节核：基于**年积日 DOY**（一年中的第几天）时间距离；
- 局部核：基于**实际相隔天数**时间距离。

> 区别于普通时空填充 STF，本方法第一步只使用该像元历史时间序列观测，不引入相邻空间像元。

### 2.2 核带宽（核的"大小"），论文最优参数

两个高斯核各自有带宽 σ，代表核的时间窗口大小，并且超过带宽阈值直接置权重为 0：

| 核函数 | 最优带宽 | 选样本规则 | 作用 |
|---|---|---|---|
| 季节核 K_seasonal | **σ_s = 30 天** | 只选用和目标日年积日相差 ≤ 30 天的样本，同时跨 5 年找同物候期样本 | 捕捉季节周期变化 |
| 局部核 K_local | **σ_t = 5 天** | 只选用距离目标日期前后 5 天之内的时间样本 | 捕捉寒潮、热浪等短期天气变化 |

> 调参过程：季节核测试 5/10/20/30/40 d；局部核测试 3/5/7 d，最终选定 30 d（季节）+ 5 d（局部）组合。

### 2.3 动态系数 α 不是核大小，而是两个时间核的占比

α 不会改变 30 天、5 天的核窗口大小，只是动态调节两个核输出权重的混合比例：
- 有效观测多、温度短期波动大 → 加大局部核（5 天短期窗口）贡献；
- 长时间连续多云、本地有效观测很少 → 更多依靠季节核（30 天物候窗口）。

### 2.4 补充关键点
1. 虽然核是时间维度，但整套 KTF‑BC 后续**偏差校正阶段会引入空间变量**（高程、NDVI、经纬度等），但这不属于核函数本身；
2. 当时间窗口内有效参考样本 < 20 个，时间填充不可靠，会用 Delaunay 三角插值补救，属于后置处理，不是核函数逻辑。

**简短总结：**
- ✅ 核只作用于**时间序列**，无空间卷积；
- ✅ 季节核时间窗口：**30 天（DOY 距离）**；局部核时间窗口：**5 天（实际日距离）**。

## 3. 使用的核函数类型

### 高斯核（Gaussian kernel，高斯时间核）
分别构建**季节高斯核**、**局部高斯核**两个高斯核。

### 3.1 季节核 K_seasonal（高斯核）
基于年积日 DOY 的环形时间距离，刻画气温年周期物候相似性：

```
K_seasonal(DOY_ij) = {
  exp(−|DOY_i − DOY_j|² / (2σ_s²)),  当 Δt < σ_s
  0,                                  其他情况
}
```
带宽 σ_s 最优取 **30 天**；超过带宽，权重直接置 0。

### 3.2 局部核 K_local（高斯核）
基于实际日时间间隔，刻画短期天气波动：

```
K_local = {
  exp(−|time_i − time_j|² / (2σ_t²)),  当 Δt < σ_t
  0,                                   其他情况
}
```
带宽 σ_t 最优取 **5 天**。

### 3.3 融合方式
二者不是卷积，是加权相加得到最终权重：

> **w_ij = α · K_seasonal + (1−α) · K_local**

α 为自适应动态系数，根据观测密度、温度短时变化强度自动调节两个高斯核的贡献占比。

**关键点：**
- 是**一维时间高斯核**，仅在时间序列运算，**不做空间高斯卷积**；
- 原生高斯函数理论上定义域无限，论文做截断：时间距离超过带宽，权重强制为 0，只使用窗口内样本参与计算。

> 原文描述：*In this study, both the seasonal kernel and the local kernel were implemented using the Gaussian kernel function.*

## 4. 动态权重系数 α 的调节细节（KTF 模块）

> 总权重：
> **w_ij = α · K_seasonal + (1−α) · K_local**

- α 控制**季节核**占比；1−α 控制**局部核**占比，α ∈ [0,1]。
- α 越大，越依赖季节周期；α 越小，越依赖临近短期观测。

### 4.1 α 计算公式（论文式 5‑7）

```
α = (1−ρ) · (1−φ)

ρ = N_valid / (2·w)          # 有效观测密度
φ = σ_local / (σ_local + 2)  # 短时温度波动强度
```

**变量释义：**

1. **w**：以目标日为中心的**对称时间窗口长度**；
2. **N_valid**：该窗口内**有效晴空 Ta 观测样本数量**；
3. **ρ**：**有效观测密度**，取值 0~1。
   - ρ 大：窗口内可用数据多；
   - ρ 小：窗口内大量云缺失，可用样本少。
4. **σ_local**：窗口内 Ta 时间序列的**标准差**，表征短期气温波动剧烈程度；
5. **φ**：波动强度变换后的值，σ_local 越大，φ 越趋近 1；σ_local → 0 时 φ → 0。

两个因子共同决定 α：
- (1−ρ)：**观测越少，(1−ρ) 越大 → α 变大，提升季节核权重**；
- (1−φ)：**温度波动越小，(1−φ) 越大 → α 变大，提升季节核权重**。

### 4.2 4 种典型场景的调节逻辑

| 场景 | ρ（观测密度） | σ_local（短期波动） | α | 主导核 | 说明 |
|---|---|---|---|---|---|
| ① 观测充足、天气多变（寒潮/热浪） | 大 | 大 | 小 | **局部核 K_local** | 优先用前后几天观测捕捉短时温度变化 |
| ② 观测充足、气温平稳 | 大 | 小 | 中等 | 季节核 + 局部核均衡 | 季节周期与临近观测兼顾 |
| ③ 连续多云，窗口内有效样本很少 | 小 | 任意 | 大 | **季节核 K_seasonal** | 临近没有可靠观测，依靠多年同 DOY 气候态做估计 |
| ④ 极端：窗口完全无有效观测（N_valid=0） | ρ=0 | − | α=1 | 完全季节核 | 完全放弃局部短期信息，只靠季节周期 |

### 4.3 边界与后置约束
1. α 输出会被钳位在 **0‑1 之间**，保证权重物理意义；
2. 即便 α 自适应调节，仍设置硬门槛：**时间窗口内有效参考样本 ≥ 20 个**才执行 KTF 时序填充；
   - 若 N_valid < 20，KTF 填充被判定不可靠，该像元改用 **Delaunay 三角插值**补缺，不再使用双高斯核加权。

### 4.4 关键注意点
1. **α 不会改变两个高斯核本身的带宽**（季节核固定 30 d，局部核固定 5 d），只改变二者输出结果的**融合比例**；
2. α 是**逐像元、逐目标日动态计算**，每个缺失像元的 α 都不一样，不是全局固定常数；
3. α 只作用 KTF 第一步（得到理论晴空气温 T_theo），**和后面 XGBoost 偏差校正模块无关**。

### 4.5 可直接粘贴进论文笔记的短句

> 该研究引入自适应系数 α 动态融合季节高斯核与局部高斯核，α 由局部时间窗口内的有效观测密度 ρ 和气温短时波动强度 φ 联合计算得到。当临近有效观测充足、气温短期波动剧烈时降低 α，增强局部核贡献以捕捉天气扰动；当连续多云、临近观测匮乏时增大 α，强化季节核，依托气温年周期保障估算稳定性。该系数仅调节两类时间核的权重占比，不改动核函数带宽参数。
